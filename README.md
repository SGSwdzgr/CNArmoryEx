## 主要功能
支持当前及上个赛季的史诗团本击杀进度、最后击杀时间、首次击杀时间，以及大秘境坚韧钥石的层数和完成时间信息速览  
**史诗团本首次击杀时间和大秘境坚韧钥石信息取自英雄榜成就，为角色所属战网帐号/战团的最早完成时间，可能并非角色本身完成，建议结合角色实际数据一并判断*

支持基于英雄榜数据的角色最后登录时间、坐骑/宠物数量，以及Raider.IO和WCL(Warcraft Logs)角色页的跳转功能

支持简单的战团成就速览，目前包括史诗钥石分数、装备升级、钥石胜利者、特色更新、战团导师：至暗之夜、至暗之夜专业查询

## 安全性和隐私
数据完全来自当前角色的英雄榜网页接口，需要对方开启英雄榜访问权限，并且你能正常访问英雄榜（即需要在登录战网/网易帐号后使用）

所有数据处理均在本地进行，无任何云端信息交互和上传，请放心使用

如果你不想被别人查询，可以在自己英雄榜页面关闭“允许角色信息被他人访问”
